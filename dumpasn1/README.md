DumpASN1 for Windows 
=====================

DumpASN1 - ASN.1 object dump/syntax check program.  
Copyright Peter Gutmann 1997 - 2021.  Last updated 12 February 2021 (D2).

DumpASN1 is a program written by [Peter Gutmann](https://www.cs.auckland.ac.nz/~pgut001/) to analyze binary ASN.1 files. 
We provide here a Windows executable `dumpasn1.exe` which is simply a compiled version of Dr Gutmann's code for the Windows platform. 
We've signed the EXE file with our signing certificate to help prevent Windows treating it as a virus - we don't claim any ownership by doing this. 

The source code is available at <https://www.cs.auckland.ac.nz/~pgut001/dumpasn1.c>

The config file `dumpasn1.cfg` is required in the same directory as the executable `dumpasn1.exe`. 
The original is available from <https://www.cs.auckland.ac.nz/~pgut001/dumpasn1.cfg>.
